# web/ (console SPA)

React + Vite + TypeScript; built into `internal/webui/dist/index.html` by `make web-build` (that file is regenerated and never committed by hand).

- Gates: `pnpm exec tsc -b --noEmit` (plain `tsc --noEmit` checks nothing: root tsconfig has only references), `pnpm exec eslint .`, `pnpm exec prettier --check .`, `TZ=UTC pnpm exec vitest run`, `make web-coverage-gate web-budget`.
- Derivation in `src/lib/`, components only render. Tests: see `README.md` "How to write a test here".
- Captions: every card/section/table/chart has a `captionId` from `src/lib/captionsets/*.ts`; guide in `README.md` "Captions and summary cards".
- Caption contracts: fits two lines at 1920×1080 (detail goes in `howToRead`, guard VIS-CAP-004); column hint (`meta.help`) stays inside its `th` (VIS-CAP-005); each advisor/alert rule id needs a sentence in `src/lib/ruleText.ts`.
- Summary card unit comes from the closed `TILE_UNITS` in `src/lib/units.ts`.
- Full HD fit (1920×1080) guards: FHD-FIT-001, FHD-MEASURE-001, FHD-INST-001, HDR-E2E-001 in `e2e/`.
- Live specs need `PGLENS_UI_BASE_URL`, `PGLENS_UI_PASSWORD`, `PGLENS_BOOTSTRAP_TOKEN`; never run two Playwright jobs at once.
- Chart groups: `ChartGroup` is a `Section` card (required `captionId`); page cards stack with `space-y-8 min-[1600px]:space-y-4`, never an `<hr>`. Axes: `valueAxis` in `metric.options.ts` (binary byte steps, clock duration steps, locale numbers).
- Charts stand alone: no `echarts.connect` group, no `dataZoom` `inside` (wheel), slider zooms only its chart and never writes the URL range; no marks the legend does not explain.
- Inline Help (`/help`): one folder per language, `src/lib/help/topics/<code>/<id>.ts` (plain strings), listed in `topics/<code>/index.ts` (order and titles per language in `catalog.ts`); English is static, other languages load lazily (`loadHelp`, chunk `help-<code>`); the guide reads in the console language (`helpLang`). Cite a console label as `{{ui:message.key}}` (resolved in the console language), never its English text. Every language keeps the English skeleton: section ids, blocks, SQL, `code`/link/ui marks (I18N-005/006, HELP-001…011 in `help.test.ts`). Pages link with `<HelpLink anchor="topic#section">` (PageHeader `help` slot); import only `@/lib/help/href` or `catalog` outside the help page (bundle budget).
- i18n (plan 006): text of a migrated area comes from `src/i18n/messages/<code>/<area>.ts` via `useT()`; a new key goes in `en` and every other catalog (I18N-001 checks keys, placeholders, plural forms). Every area is migrated (plan 006 F3); I18N-021 is the pseudo-locale guard of the shell. Server texts (findings, readiness) come rendered in the language of the `X-Pglens-Lang` header, which `api/client.ts` always sends. Guard I18N-002: local ESLint rule `pglens/no-literal-string` (`eslint-rules/`, file list `i18nMigrated` in `eslint.config.js`) flags JSX text and text props written as literals. `lib/format/*` default to the active language (`activeIntl()`); timestamps stay ISO. Domain texts (captions, column hints, rule sentences, glossary, units) of other languages live in `src/i18n/domain/<code>/` (English stays in `src/lib`); read them through `captionOf`/`columnHelpOf`/`ruleText`/`glossaryOf`/`formatUnit`, never `CAPTIONS[id]` in a component. Terms: `docs/i18n/glossary.md`.
- Plan 007 areas: `features/logs` (+ `lib/logs.ts`), `features/workbook` (+ `lib/workbook.ts`, `api/workbooks.ts`), period compare (`ComparePeriodPicker`, `useComparePeriods`, `lib/compare.ts`, `AshCompare`, `QueryCompare`), plans (`PlanSamples`, `PlanStats`, `PlanCompare`, `lib/autoPlans.ts`, `lib/planTree.ts`), `instance/AutovacuumRuns` + `ProcessesPanel`, `indexes/IndexValidation`, `RollupNote` + `lib/rollup.ts`, `TraceId` + `lib/traceLink.ts`. Live console steps: `e2e/parity.spec.ts` (needs `test/parity/scenario.sh` data).
- Vitest gotcha: the on-disk module cache `node_modules/.vitest-cache` keys by file content, so a file that `import.meta.glob` should pick up (new locale, new domain) stays invisible until the cache is cleared (`rm -rf node_modules/.vitest-cache`).
