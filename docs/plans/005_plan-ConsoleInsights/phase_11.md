## Local design context
Plan revision: 1.
- D14 (cluster rename), D15 (instance alias), I-4 (migrations are additive), I-6, I-10 not involved (no secret).
- Recon: `clusters(tenant_id, cluster_id bigint, name text NULL, id_source, first_seen)`; `GET /api/v1/clusters` (`internal/server/api.go:335`) already returns `name`; no code writes it; inventory upserts at `internal/server/inventory.go` ~326–353 only set `id_source`; cluster ids are `uint64` bit patterns stored as `bigint` (see `internal/store/clusterid.go`; the REST `{id}` is the decimal uint64 string the other `/clusters/{id}/…` routes take — reuse their parser). Display fallbacks: `ClusterCard.tsx` shows `cluster.name ?? 'Unnamed cluster'`, `ClusterPage.tsx` title `cluster.name ?? 'Cluster <id>'`, `InventoryTables.tsx` `cluster_name ?? cluster_id`. Instances: `instances(instance_id uuid PK, tenant_id, cluster_id, agent_id, addr, …)`; instance summaries expose `addr`, `port`, `role`, `cluster_id`, `cluster_name`.
- Name rules (both): trim; empty after trim or JSON `null` → clear (store NULL); 1–64 characters after trim; no control characters (`unicode.IsControl`), no leading/trailing spaces after trim; Unicode allowed; uniqueness per tenant, case-insensitive (`lower(name)`); violation → `409 {"error":"name already in use"}`.
- Migrations (next free numbers after `0021_purge_credential_plans.sql`; use the next free number at implementation time and keep the names): `0022_cluster_name_unique.sql` = `CREATE UNIQUE INDEX IF NOT EXISTS clusters_name_uniq ON clusters (tenant_id, lower(name)) WHERE name IS NOT NULL;`, `0023_instance_display_name.sql` = `ALTER TABLE instances ADD COLUMN IF NOT EXISTS display_name text; CREATE UNIQUE INDEX IF NOT EXISTS instances_display_name_uniq ON instances (tenant_id, lower(display_name)) WHERE display_name IS NOT NULL;` (both idempotent, metadata tables, not hypertables).
- Auth/CSRF: copy `updateAlertRule` (`PUT /api/v1/alert-rules/{rule_id}`, see its handler and `refuseCrossOriginWrites` in `internal/server/http.go`).
