## Purpose and source map
Documented (README.md): pglens = self-hostable monitoring for PostgreSQL fleets, focused on replication and wait-event analysis (ASH). Agent scrapes instances through a version- and permission-aware check registry; server ingests a versioned JSON envelope into TimescaleDB; `pglens-server` also serves the embedded web console (Fleet, Cluster, Instance, Wait-event analysis, Queries, Locks, Advisor, Alerts, Settings, Index analysis). Alpha releases; product limits in `docs/LIMITS.md`.
