# pglens (postgres-analyze)

Go PostgreSQL monitor: `cmd/pglens-agent` (collects, pushes) and `cmd/pglens-server` (TimescaleDB store, API, embedded console from `web/`, see `web/CLAUDE.md`). Logic in `internal/*` (advisor, alert, check, topology, server, …).

- Go gates: `make fmt-check lint vet-tags test`; integration `make test-integration` (`-tags=integration`, needs Docker).
- Alert notifications: server `AlertDescriber` (`internal/server/describe*.go`) adds a `notify.Detail` (table, ctid, sessions, read-only SQL); texts in `internal/i18n/locales/*.json` (same keys and placeholders in every locale, TestCatalogParity), language `PGLENS_LANG` (en default), times in `PGLENS_TZ` (IANA, UTC default; deploy Europe/Rome); the console takes zone and language from `/api/v1/session` (override in Settings › Preferences), URLs/exports/API stay UTC. Agent watcher `internal/watch` (read-only, rides ASH, `checks.watch.enabled`) files `*_captured` events; a deadlock missed by the 1 Hz probe is rebuilt from `pg_stat_database.deadlocks` + sessions seen waiting (`DeadlockLookback`). Console view Locks › Captured incidents (`web/src/lib/incidents.ts`) reads them via `/api/v1/events?instance_id=&type=a,b`. A new event type needs `web/src/lib/events.ts` + help (UI-CLUS-036/052 scan Go lines matching `Type:`/`EventType`).
- Server texts per language: advisor findings (`Finding.say`, catalogs `internal/i18n/locales/advisor_<rules file>.<code>.json`) and readiness (`Input.Locale`, `readiness.<code>.json`) render in the language of header `X-Pglens-Lang` (no header = English, stored text stays English); tests run with `strictMessages` (missing key or argument panics).
- Notification language per channel (plan 006 F7): `notification_channel_languages`, `PUT /api/v1/notification-channels/{kind}/language`; held in `notify.Slot.Locale()`, the notifier builds one `notify.Detail` per language (`alert.LocaleDescriber`); empty = server `PGLENS_LANG`. The test message stays English (C9).
- Console i18n (plan 006, status in its `STATE.md`): registry `web/src/i18n/locales.json`; catalogs `web/src/i18n/messages/<code>/<area>.ts` (en defines the keys, others typed `Translation<typeof en>`); components use `useT()`/`useFormat()` from `@/i18n/react`. Language: Preferences › Language, else `PGLENS_LANG` (session), else browser, else en. Non-en catalogs are lazy chunks `i18n-<code>` (budget 64 KiB gzip). `web/src/i18n/testdata/format-cases.json` runs in vitest and in Go (`internal/i18n/shared_test.go`). `en-XA` pseudo-language only in dev/test. Vacuum, WAL, checkpoint, deadlock, ctid, xmin, `pg_*`, setting names, SQL stay English.
- Adding a language: README "Adding a language" (registry `locales.json`, console catalogs + domain + help folder, Go `internal/i18n/locales/*.<code>.json`, `decimalComma`, glossary, format cases); gate `make i18n-check` (local; CI runs the same tests in `test`/`web-coverage-gate`). Live check in Italian: `web/e2e/i18n_it.spec.ts` (I18N-E2E-001: Italian fits Full HD wherever English fits). e2e selectors stay language-neutral (`nav[data-table-pager]`, `table[data-chart-data]`).
- Top-N checks (`table_stats`, `index_stats`, `stat_statements`) prefilter in SQL: `LIMIT prefilterLimit()` per ranking, ordered exactly as `cardinality.Selector` (score DESC, key `COLLATE "C"`), plus `scopedSelectors.retained` keys; change a ranking in Go and SQL together. `stat_statements` ships `hashtextextended(query,0)`, texts only via `statementTextsQuery`.
- Findings card: "How to verify" SQL per rule in `web/src/lib/findingCheck.ts`, always `BEGIN TRANSACTION READ ONLY … ROLLBACK`, catalogs/stats only; must run on PG 15 and 18 (version-dependent views via `query_to_xml`, generic plans via `PREPARE` + `plan_cache_mode`). Statement text from server `query_texts` (`query_text` on findings).
- Plans: `docs/plans/<NNN>_plan-*/` (pev-v3); live status only in each plan's `STATE.md`.
- Live lab stack lives outside the repo: `/home/agent/pglens-odoo-stack` (its `README.md`; `.env` holds secrets, never print it). Since plan 005 7.2 it runs HA: 3 PostgreSQL 18 nodes + `hactl` (`test/ha/hactl`, admin `127.0.0.1:8008/status`); marker `ha/ACTIVE`; compose needs `-f compose.yml -f ha/compose.ha.yml`; never start a stopped DB node by hand (`ha/rejoin.sh`).
- Live e2e gotchas: UI sessions live in server memory (restart = sign-in again; `signedInPage` handles it); `COV-E2E-001` must start ≤ 2 min after `deploy.sh`; HA agent config is `ha/agent.ha.yaml`.
- Destructive stack steps need a VERIFIED backup < 24 h (`backup.sh` + `verify_backup.sh`, dir `/home/agent/odoo-backups`).
- Console assets: the Vite plugin `pglens-gzip` writes `name.gz` beside every text file > 1 KiB; `SPAHandler` (`internal/server/webui.go`) sends it to gzip clients. No run-time compression.
- Never commit `internal/webui/dist/index.html`, `.claude/`, `web/src/node_modules/`.
- Real deploy VMs (not the lab): server `ubuntu@172.31.20.35:/home/ubuntu/pglens`, agent `ubuntu@172.31.35.203:/home/ubuntu/pglens-client`. Roll out dev images (`docker save | ssh … docker load`), back up `compose.yml` before swapping the tag.
